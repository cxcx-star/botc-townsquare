# 血染钟楼 · 桌面同步

线下开团用的小工具：**平板摆在桌上当「城镇广场」，手机握在说书人手里当「魔典」**。

手机改了谁死、谁还留着鬼票，平板上的名牌立刻盖血印、换票面；平板上的名牌可以随手拖动，
摆成你们那张桌子的形状。手机端直接跑《染·钟楼谜团》**官方魔典本体**，界面和操作跟官方一模一样。

- **零依赖**：一个 Node 文件就能跑，不需要数据库、不需要装包
- **断网可用**：官方魔典和角色表都托管在本地
- **两种部署**：局域网直连（最快）或 Cloudflare 免费托管（发给外地朋友）

### 🔗 在线版：<https://botc-2xf.pages.dev/>

不用安装、不用开电脑，浏览器直接打开就能用。手机和平板各开一个，不用连同一个 Wi-Fi。

## 快速开始（局域网）

需要 Node 18 或更新版本。

```bash
cd clocktower-table
./start.sh          # 或者 node server.js
```

终端会打印地址：

```
手机（本机）    http://127.0.0.1:8787/
平板（同 Wi-Fi） http://192.168.x.x:8787/
                https://192.168.x.x:8443/   （浏览器拦 http 时用这个）
```

默认同时开 HTTP（8787）和 HTTPS（8443）。**手机上优先用 HTTPS**：很多安卓浏览器默认禁止
明文 HTTP，会报 `ERR_CLEARTEXT_NOT_PERMITTED`。自签名证书第一次会提示不安全，点「高级 → 继续前往」即可。

```bash
./start.sh stop              # 停止
node server.js --port 9000   # 自定义端口
```

### 两台设备怎么连

1. 平板浏览器打开局域网地址 → 点「城镇广场」（没有房间会自动建一个）
2. 手机浏览器打开同一个地址 → 点「魔典」
3. 手机上是官方魔典，按 `A` 或点右下角「＋ 座位」加座位，填名字、点角色

地址建议存书签：魔典是 `.../gs/?room=DEMO`，广场是 `.../square.html#DEMO`，`room=` 后面就是 4 位房间码。

## 手机 · 官方魔典

手机端用的是**官方魔典本体**，整套托管在 `public/gs/`，角色表也缓存到了本地，断网照样能开。
我加了一层很薄的桥（`public/gs-bridge.js`）：读它的 Vuex 状态，把「座位 / 名字 / 角色 / 生死 / 鬼票」
整份快照推给本地服务，平板就能实时跟着变。

![魔典](screenshots/grimoire.png)

**在官方界面里怎么操作：**

- 按 `A` 加座位；触屏设备右下角有「＋ 座位」按钮（官方网页版只有键盘快捷键，这个是补的）
- 点角色托盘里的角色 → 点座位，分配身份
- **点杯子顶部**盖黑纱：存活 → 已亡 · 带票 → 已亡 · 无票 → 复活
- 右上角 ⚙ 是官方菜单：切换剧本、白天 / 夜晚、角色能力表 `R`、夜晚顺序表 `N`

右下角的浮动按钮（触屏设备才有）：

| 按钮 | 作用 |
|---|---|
| **＋ 座位** | 加一个座位 |
| **提示** | 打开信息提示工具（页内浮层，关掉回魔典） |
| **下发** | 下发身份（页内浮层） |
| **首页** | 回到「选广场 / 选魔典」的启动页 |

### 选择剧本

⚙ → **选择剧本** → 「官方剧本」或「缝合剧本」页签 → 点封面即可切换，角色池立刻换成该剧本的角色。
切完剧本，平板的标题也会跟着变。

### 信息提示

十条常用耳语：

```
你是 ___          这名玩家是 ___        该角色的技能作用于你 ___
这些角色不在场 ___（可多选）             他是恶魔
你昨天提名了吗     你昨天投票了吗        做出你的选择
你要使用你的能力吗 他们是你的爪牙
```

用法（记录式）：

1. **点提示卡**，或点顶部 **「角色」** 从列表里挑角色 —— 按下的顺序会记录在下面的记录条里
2. 角色在记录条里是一枚小 token，点它可以删除
3. 最后按底部的 **「显示」**，记录的内容按顺序铺满屏幕；角色画成 token，名字写在 token 里面
3. 选完是全屏大字，把手机递给玩家

角色列表会**按当前剧本过滤**（切到黯月初升就只列那 30 个）。「这些角色不在场」支持多选。

### 下发身份

把魔典里**已经分配好的角色**发给座位：

- **按已分配角色**：每个座位领自己那份，不打乱
- **完全随机**：把这几个角色打乱后重新发

流程：说书人点开始 → 手机传给 1 号 → 翻一张牌看身份 → 「记住了，交给下一位」→ 2 号… → 全部领完。
**每翻一张就把「座位 → 角色」写回房间**，发完打开魔典就是刚才抽到的结果（座位也会自动补齐）。

## 直连官方线上房间（可选）

官方魔典的「创建小镇」是一个 WebSocket 中继：主持人在 `<房间>/host`，旁观者连进同一条频道就能拿到状态。
所以平板也可以**不经过手机桥接**，直接旁观官方房间：

1. 手机打开官方魔典，按 `C`「创建小镇」起个房间名（≤10 个字符）
2. 平板广场右下角点「官方房间」→ 输入这个名字
3. 左上角出现绿色房间名就通了

也可以写进地址：`.../square.html?watch=房间名#房间码`，刷新会自动重连。
此模式要求能上外网；云端版不支持。

## 数据与清理

- 每个房间自动存到 `data/rooms/<房间码>.json`，服务重启后自动恢复
- **闲置 1 小时的房间会自动清除**（没有任何设备连着时才清，正在用的局不受影响）
  - 局域网：每 5 分钟扫一次
  - 云端：每次读取房间列表时惰性清理
  - 可用环境变量调整：`CT_ROOM_TTL=1800000 CT_SWEEP_EVERY=60000 node server.js`
- 另一台设备打开空的官方魔典时，空快照会被忽略，不会把桌上已有的牌冲掉

## 云端部署（Cloudflare，免费）

仓库里带了 `wrangler.jsonc`、`cloudflare/src/index.js` 和 `functions/`：后端挂在 **Worker + Durable Object**，
静态页面由 **Pages** 提供，`/api` 和 `/ct` 由 Pages Functions 在服务端转发（浏览器不直接解析 `workers.dev`）。

- 适合：把链接发给外地朋友、不想一直开着手机上的服务
- 不适合：断网场景、官方线上房间监听

**当前线上地址：[https://botc-2xf.pages.dev/](https://botc-2xf.pages.dev/)**
（Pages 提供页面和转发，Worker 存房间状态；`workers.dev` 域名在国内会被 DNS 污染，所以不直接用它。）

详细步骤见 [cloudflare/README.md](cloudflare/README.md)。

```bash
npx wrangler deploy     # 或用 Cloudflare 控制台 Workers → Connect to Git
```

## 常见问题

**手机提示 `ERR_CLEARTEXT_NOT_PERMITTED`？**
用 HTTPS 地址（`https://192.168.x.x:8443/`），点「高级 → 继续前往」。

**手机打不开？**
确认两台设备在同一个 Wi-Fi；用局域网 IP 而不是 `localhost`；服务端防火墙放行 8787。

**改了代码但手机上没变化？**
手机浏览器会缓存 `gs-bridge.js`，下拉刷新或关掉标签重开。

**平板会自动锁屏？**
网页的屏幕常亮（Wake Lock）只在 HTTPS 或 localhost 下生效，局域网 http 下可能拿不到。
把平板自动锁屏时间调长，或插着电开「充电时不锁屏」。

**下发完魔典没变？**
点「完成下发」后魔典会立刻拉取；若仍不变，刷新魔典页面（旧缓存的 `gs-bridge.js`）。

**安全吗？**
纯局域网工具，没有登录、没有加密。别把端口映射到公网。

## 技术说明

- 后端：Node 内置 `http`，**零第三方依赖**
- 同步：浏览器 `EventSource`（SSE）推全量快照 + `POST /api/room/:code/intent` 写入；云端为 2 秒轮询
- 手机端乐观更新：先本地应用意图，收到回执后再对齐，连续点击不会回跳
- 状态写入防抖 180ms 落盘（原子写：先写 `.tmp` 再 rename）
- 官方魔典 ↔ 房间：单向推送（订阅 + 900ms 兜底）+ 反向往回写（2.5 秒对比，一次性提交，避免半新半旧）

主要文件：

```
server.js                     HTTP + SSE + 房间存储 + 闲置清理
start.sh                      一键启停（打印当前局域网地址）
public/index.html             启动页（选设备、看地址、工具入口）
public/square.html            平板 · 城镇广场
public/deal.html              下发身份（传手机领牌）
public/xrh.html               信息提示（十条耳语）
public/gs/                    官方魔典（本地托管，含素材）
public/gs-bridge.js           官方魔典 ↔ 房间的双向桥
public/editions/*.json        各剧本的角色表
public/edition-list.json      剧本列表
public/ct-role-data.json      官方角色表缓存（205 个）
public/assets/seat/           官方筹码素材
public/js/model.js            共享数据模型（服务端 / 浏览器同一份）
public/js/store.js            客户端状态仓库（乐观更新 + 回执校准）
public/js/square.js           环形排布、拖动、长按标记、样式切换
cloudflare/src/index.js       Worker 后端（Durable Object）
functions/                    Pages Functions（服务端转发 /api、/ct）
```
